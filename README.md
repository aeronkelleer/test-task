# Приложение для поиска автозапчастей по артикулу

## Demo link

https://aeronkelleer.github.io/test-task/

## Технологии

- React
- Redux Toolkit
- JavaScript
- SCSS
- Vite

## Deploy

- Проект автоматически публикуется на GitHub Pages через GitHub Actions при каждом push в ветку `main`

- Workflow находится в `.github/workflows/deploy.yml`. Он устанавливает зависимости, собирает проект и публикует содержимое папки `dist`
